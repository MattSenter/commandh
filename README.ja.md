<h1 align="center">CommandH</h1>

<p align="center">
  Macで最後に残ったアプリも<b>Cmd+H</b>で非表示にして、ちゃんとデスクトップが見えるようにします。
</p>

macOSには妙なルールがあります。**最後に表示されているアプリは非表示にできない**のです。ほかのアプリがすべて非表示になっている状態で、残った1つのアプリでCmd+Hを押しても何も起こりません。ウインドウはそのまま残り、デスクトップにたどり着けません。

CommandHは、この問題を解決する小さな無料のオープンソースのメニューバーアプリです。CommandHを実行しておけば、最後のアプリでも、Cmd+Hがいつも同じように効きます。

- 許可が必要な権限はありません（アクセシビリティも画面収録も不要）
- ネットワーク通信なし、分析なし、データの収集なし
- メニューバーに常駐します。お好みでアイコンを出さずに動かすこともできます
- macOS 14 Sonoma以降が必要です

## インストール

CommandHは現在、ソースからビルドしてインストールします。1分ほどで終わります。

1. Appleのコマンドラインツールがない場合は、インストールします:
   ```sh
   xcode-select --install
   ```
2. このリポジトリをクローンしてビルドします:
   ```sh
   git clone https://github.com/MattSenter/commandh.git
   cd commandh
   ./build.sh --install
   ```
   `CommandH.app`がビルドされ、アプリケーションフォルダにコピーされて、起動します。
3. 設定ウインドウが表示されます。**システム**で**ログイン時に開く**をオンにしておくと、CommandHがいつでも使える状態になります。

これで完了です。いつもどおりにアプリを非表示にしてください。最後の1つになっても、Cmd+Hで非表示にできるようになります。

## CommandHの使い方

新しく覚えることはありません。これまでどおりCmd+Hを使うだけです。

- **2つ以上のアプリが表示されているときは、** CommandHは何もせず、Cmd+Hはこれまでとまったく同じように動作します。
- **表示されているアプリが1つだけのときは、** CommandHが手助けして、Cmd+Hが効くようにします。その後の動作は、[設定](#設定)で選んだ方法によって変わります。

非表示にしたアプリを元に戻すには、いつもどおりDockのアイコンをクリックするか、Cmd+Tabで切り替えます。

### 最後のアプリの2つの扱い方

| | アプリを非表示にする（デフォルト） | デスクトップを表示 |
|---|---|---|
| 見え方 | ほかのアプリでのCmd+Hと同じように、アプリが完全に非表示になります | ウインドウが画面の端に移動します |
| 元に戻す方法 | Dockのアイコンをクリックするか、Cmd+Tabを使います | もう一度Cmd+Hを押すか、アプリをクリックします |
| Dockのアイコン | 表示中のアプリが1つ以下のあいだ、CommandHのアイコンがDockに表示されます | Dockには一切表示されません |
| おすすめの人 | 本当に非表示にしたい人 | CommandHをDockに表示したくない人 |

**「アプリを非表示にする」モードでDockにアイコンが表示されるのはなぜですか？** macOSがアプリの非表示を拒否するのは、画面に通常のアプリが1つも残らなくなる場合だけです。CommandHは一時的に通常のアプリ（Dockにアイコンがあるアプリ）になり、最後のアプリを「最後」ではなくします。通常のアプリには必ずDockのアイコンが付き、これを避ける方法はありません。2つ以上のアプリが表示されると、アイコンはすぐに消えます。詳しくは[仕組み](#仕組み)を参照してください。

## 設定

設定ウインドウは、アプリケーションフォルダ（またはSpotlightやLaunchpad）からCommandHを開くか、メニューバーのアイコンから**設定…**を選ぶか、CommandHのアイコンがDockに表示されているときにそれをクリックすると開きます。サイドバーには、**非表示**、**システム**、**プライバシー**、**その他のプロジェクト**（同じ開発者のほかのアプリ）、**情報**（バージョン情報とリンク）の5つのパネルがあります。

<p align="center">
  <img src="docs/images/settings-light.png" width="440" alt="ライトモードのCommandHの設定ウインドウ">
  <img src="docs/images/settings-dark.png" width="440" alt="ダークモードのCommandHの設定ウインドウ">
</p>

| 設定 | パネル | 内容 |
|---|---|---|
| **有効** | 非表示 | CommandHを終了せずにオン/オフを切り替えます。オフのときは、Cmd+Hは標準のmacOSと同じ動作になります。 |
| **表示中のアプリが1つだけのとき** | 非表示 | **アプリを非表示にする**か**デスクトップを表示**かを選びます。[上の比較](#最後のアプリの2つの扱い方)を参照してください。 |
| **メニューバーに表示** | システム | メニューバーの⌘Hアイコンを表示または削除します。オフにすると、CommandHは見えない状態で動作します。このウインドウに戻るには、アプリケーションフォルダからCommandHを開きます。 |
| **ログイン時に開く** | システム | ログイン時にCommandHを自動的に起動します。このウインドウは開かず、静かに起動します。 |
| **CommandHを終了** | システム | アプリを実際に終了します。ウインドウを閉じても（Cmd+Qを押しても）、ウインドウが閉じるだけでCommandHは実行され続けます。 |

設定は自動的に保存され、すぐに反映されます。

## メニューバーのメニュー

メニューバーの⌘Hアイコンをクリックすると、同じ設定にすばやくアクセスできます。

<p align="center">
  <img src="docs/images/menu.png" width="537" alt="「Cmd+Hで非表示にできないとき」サブメニューを開いたCommandHのメニューバーのメニュー">
</p>

- **有効**: CommandHのオン/オフを切り替えます。
- **Cmd+Hで非表示にできないとき**: **アプリを非表示**か**デスクトップを表示**を選びます。
- **メニューバーに表示**: チェックを外すとアイコンが消えます。Commandキーを押しながらアイコンをメニューバーの外にドラッグして消すこともできます。
- **ログイン時に開く**: ログイン時にCommandHを起動します。
- **設定…**: 設定ウインドウを開きます。
- **CommandHを終了**: アプリを終了します。

## キーボードショートカット

CommandHの設定ウインドウが最前面にあるとき:

| ショートカット | 内容 |
|---|---|
| Cmd+W | 設定ウインドウを閉じます。CommandHは実行され続けます。 |
| Cmd+Q | こちらもウインドウを閉じるだけで、CommandHは実行され続けます。うっかりCmd+Qを押してもオフになりません。本当に終了するには**CommandHを終了**を使います。 |
| Cmd+H | ほかのアプリと同じようにCommandHを非表示にします。 |
| Cmd+, | 設定を開きます。 |

## トラブルシューティング

**最後のアプリでCmd+Hを押しても、まだ何も起こりません。**
CommandHが実行中であること（アプリケーションフォルダから開いてください）と、**有効**がオンになっていることを確認してください。**デスクトップを表示**を使っている場合は、「デスクトップを表示」の項目がグレイ表示になっていないか確認してください（下記を参照）。

**DockにCommandHのアイコンが表示されました。**
**アプリを非表示にする**モードでは、表示中のアプリが1つ以下のときにアイコンが表示されるのは想定どおりの動作です。2つ目のアプリが表示されると消えます。まったく表示したくない場合は、**デスクトップを表示**に切り替えてください。

**すべてを非表示にした後、デスクトップをクリックしたらFinderのウインドウが戻ってきました。**
これはmacOSの通常の動作です。デスクトップをクリックするとFinderに切り替わり、非表示のアプリに切り替えるとそのウインドウが再び表示されます。クリックしていない非表示のアプリは、非表示のままです。

**「デスクトップを表示」モードで、ウインドウの端がまだ見えます。**
macOSの「デスクトップを表示」はそういう仕組みです。もう一度Cmd+Hを押すか、ウインドウの端をクリックすると、すべて元に戻ります。完全に非表示にしたい場合は、**アプリを非表示にする**を使ってください。

**「デスクトップを表示」の項目がグレイ表示になっています。**
「デスクトップを表示」は、macOSの内部機能を利用しています。将来のmacOSでこの機能がなくなった場合、CommandHは誤動作を避けるためにこの項目をグレイ表示にします。**アプリを非表示にする**は引き続き使えます。

**メニューバーのアイコンをオフにしたら、CommandHが見つかりません。**
アプリケーションフォルダからCommandHを開いてください。設定ウインドウが表示されるので、**システム**でアイコンを再びオンにできます。

**「ログイン時に開く」がオンのままになりません。**
macOSでは、決まった場所にあるアプリしかログイン時に開けません。CommandHがアプリケーションフォルダにあることを確認してから（`./build.sh --install`を使えばそこに入ります）、もう一度設定をオンにしてください。

**最後のアプリを非表示にすると、メニューバーに「CommandH」と表示されます。**
**アプリを非表示にする**モードでは、最後のアプリが非表示になった後にCommandHがアクティブなアプリになるため、メニューバーにその名前が表示されます。任意のアプリかデスクトップをクリックすれば、元の作業に戻れます。

## 仕組み

CommandHを作る前に、最後に表示されているアプリを直接非表示にする方法を、見つかる限りすべて試しました。結果はすべて失敗でした:

| 方法 | 結果 |
|---|---|
| `NSRunningApplication.hide()` | 拒否される |
| AppleScript（`set visible of process ... to false`） | 最後に表示されているアプリの場合は拒否される |
| アクセシビリティ（`kAXHiddenAttribute`） | 成功を返すが、何も非表示にならない |
| 非公開のLaunchServices（`_LSSetApplicationInformationItem`） | 成功を返すが、何も非表示にならない |
| Carbonの`ShowHideProcess` | 拒否される |

これらはすべて、macOS内部の同じチェックに行き着きます。そしてそのチェックが数えるのは**通常のアプリ**、つまりDockにアイコンがあるアプリだけです。メニューバー専用のアプリは数に入りません。強制的に非表示にしても、macOSは常に何かが画面に表示されるように、直前に使っていたアプリをすぐに再表示してしまいます。

**アプリを非表示にする**は、このルールの範囲内で動作します。表示中のアプリが1つ以下になると、CommandHは自身を通常のアプリに切り替え、1×1ピクセルのほぼ透明なウインドウを持ちます。すると最後のアプリはもう「最後」ではなくなるため、そのアプリ自身のCmd+Hが通常どおり効き、macOSはほかのアプリを再表示する代わりにCommandHにフォーカスを渡します。2つ以上のアプリが表示されると、CommandHはメニューバー専用のアプリに戻ります。

**デスクトップを表示**は別の方法をとります。最前面のアプリだけが表示されているあいだ、CommandHはCmd+Hをグローバルホットキーとして登録し（その状態でなくなるとすぐに解除します）、macOS標準の「デスクトップを表示」を実行します。それ以外の場面では、Cmd+Hはそのままアプリに届きます。

どちらの方法も権限は一切不要で、CommandHが画面やキー入力を読み取ることはありません。グローバルホットキーが存在するのは、「デスクトップを表示」モードで、かつアプリが1つだけ表示されているあいだだけです。

アプリ全体は、[`Sources/`](Sources)にある500行未満のSwiftコードです。

## アンインストール

1. メニューバーのアイコン、または設定ウインドウの**システム**パネルから**CommandHを終了**を選びます。
2. **ログイン時に開く**をオンにしていた場合は、先にオフにするか、「システム設定」>「一般」>「ログイン項目」でCommandHを削除します。
3. `/Applications/CommandH.app`をゴミ箱にドラッグします。
4. 必要に応じて、設定も削除します:
   ```sh
   defaults delete com.mattsenter.CommandH
   ```
